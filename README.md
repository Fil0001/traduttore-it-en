# Traduttore Italiano - Inglese (offline)

Dizionario italiano-inglese integrato in un singolo file HTML. Nessuna installazione, nessun account, nessuna chiamata di rete: la traduzione avviene nel browser.

## Uso

Apri l'indirizzo pubblicato con GitHub Pages, oppure scarica `index.html` e apri il file con un doppio clic.

Per la **dettatura vocale** la pagina deve essere servita da un indirizzo `https://` (come la pagina GitHub Pages): i browser non concedono il microfono ai file aperti dal disco. La **pronuncia della traduzione** usa le voci di sistema e funziona anche offline.

## Contenuto

- circa 700 voci italiane e altrettante inglesi, piu circa 130 espressioni fisse
- traduzione in entrambe le direzioni con evidenziazione di cio che manca
- input vocale (Web Speech Recognition) e sintesi vocale (Speech Synthesis)
- nessuna dipendenza, nessuna build: un solo file HTML

## Nota

E un dizionario con sostituzione parola per parola, non un traduttore statistico: adatto a parole singole, frasi brevi, email semplici e liste di termini.
